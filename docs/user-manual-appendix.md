# ภาคผนวก ก
# คู่มือการใช้งานระบบ BudgetMate (User Manual)

## ก.1 บทนำ

BudgetMate เป็นแอปพลิเคชันสำหรับบันทึกรายรับและรายจ่ายส่วนบุคคล ช่วยให้ผู้ใช้ตรวจสอบยอดคงเหลือ ดูประวัติธุรกรรม วิเคราะห์การใช้จ่าย และติดตามเป้าหมายการออม นอกจากนี้ยังสามารถอ่านข้อมูลจากภาพสลิปหรือใบเสร็จเพื่อนำมาประกอบการบันทึกรายจ่ายได้

คู่มือนี้อธิบายการใช้งานโดยอ้างอิงชื่อเมนูภาษาไทยและการทำงานของโปรเจกต์ ณ วันที่ 12 ตุลาคม 2569 เหมาะสำหรับผู้ใช้ทั่วไปที่เริ่มต้นใช้งานระบบ

## ก.2 การเตรียมความพร้อม

1. เปิดแอปพลิเคชัน BudgetMate ที่ติดตั้งไว้บนอุปกรณ์
2. เตรียมอีเมลสำหรับสมัครสมาชิก หรือบัญชี Google สำหรับเข้าสู่ระบบ
3. เชื่อมต่ออินเทอร์เน็ตสำหรับการสมัครสมาชิก เข้าสู่ระบบ และบันทึกข้อมูลบัญชี
4. หากต้องการถ่ายภาพหรือเลือกภาพ ให้อนุญาตการเข้าถึงกล้องหรือรูปภาพเมื่ออุปกรณ์ร้องขอ

ยอดเงินใน BudgetMate คำนวณจากรายการที่ผู้ใช้บันทึก จึงไม่ใช่ยอดเงินที่ดึงจากบัญชีธนาคารโดยอัตโนมัติ การกดโอนเงินเข้าเป้าหมายการออมเป็นการจัดสรรเงินในบันทึกของแอป ไม่ได้สั่งโอนเงินจริงผ่านธนาคาร

## ก.3 การสมัครสมาชิกและตั้งค่าเริ่มต้น

1. ที่หน้าเข้าสู่ระบบ เลือก **สมัครสมาชิก**
2. กรอกชื่อ อีเมล รหัสผ่าน และยืนยันรหัสผ่าน
3. กำหนดรหัสผ่านให้มีอย่างน้อย 6 ตัวอักษร และไม่เกิน 128 ตัวอักษร โดยประกอบด้วยตัวพิมพ์เล็กภาษาอังกฤษ ตัวพิมพ์ใหญ่ภาษาอังกฤษ ตัวเลข และสัญลักษณ์ เช่น `!` หรือ `@` อย่างน้อยประเภทละ 1 ตัว
4. ตรวจสอบว่ารหัสผ่านทั้งสองช่องตรงกัน แล้วกด **สมัครสมาชิก** หากระบบแจ้งว่ารหัสผ่านเดาง่าย ให้เปลี่ยนรหัสผ่านตามคำแนะนำบนหน้าจอ
5. เมื่อเข้าสู่หน้าตั้งค่าเริ่มต้น เลือกภาษา **ไทย** หรือ **English** และตรวจสอบสกุลเงิน ซึ่งรุ่นปัจจุบันมีตัวเลือก **THB (บาทไทย)**
6. กด **ถัดไป** เพื่อบันทึกการตั้งค่าและเข้าสู่หน้าหลัก

หากระบบแจ้งว่าอีเมลถูกใช้งานแล้ว ให้กลับไปเข้าสู่ระบบด้วยบัญชีเดิม หรือใช้ขั้นตอนลืมรหัสผ่าน

## ก.4 การเข้าสู่ระบบและการกู้คืนรหัสผ่าน

### ก.4.1 เข้าสู่ระบบด้วยอีเมล

1. กรอกอีเมลและรหัสผ่านที่ใช้สมัครสมาชิก
2. กด **เข้าสู่ระบบ**
3. เมื่อเข้าสู่ระบบสำเร็จ ระบบจะแสดงหน้าหลักของผู้ใช้

### ก.4.2 เข้าสู่ระบบด้วย Google

1. กดปุ่มเข้าสู่ระบบด้วย Google
2. เลือกบัญชี Google และดำเนินการตามหน้าต่างที่ปรากฏ
3. หากเป็นบัญชีใหม่ในระบบ ให้เลือกภาษาและสกุลเงินในหน้าตั้งค่าเริ่มต้น แล้วกด **ถัดไป** ส่วนบัญชีเดิมจะเข้าสู่หน้าหลัก

### ก.4.3 ลืมรหัสผ่าน

1. ที่หน้าเข้าสู่ระบบ เลือก **ลืมรหัสผ่าน?**
2. กรอกอีเมลที่ใช้สมัครสมาชิก แล้วกดปุ่มส่งคำขอรีเซ็ตรหัสผ่าน
3. เปิดอีเมลที่ได้รับและกดลิงก์เพื่อตั้งรหัสผ่านใหม่ หากไม่พบอีเมล ให้ตรวจสอบโฟลเดอร์จดหมายขยะ
4. กลับมายังแอปและเข้าสู่ระบบด้วยรหัสผ่านใหม่

## ก.5 หน้าหลักและเมนูใช้งาน

หลังเข้าสู่ระบบ ผู้ใช้สามารถดูข้อมูลสรุปทางการเงินและเลือกใช้งานผ่านแถบเมนูด้านล่างได้ดังนี้

| เมนู | การใช้งาน |
| --- | --- |
| หน้าหลัก | ดูรายรับรวม รายจ่ายรวม คงเหลือสุทธิ และแนวโน้มรายจ่าย |
| กระเป๋าเงิน | ดูยอดคงเหลือรวม เข้าถึงรายการรายรับ–รายจ่าย ประวัติ และเป้าหมายการออม |
| เพิ่มรายการ | บันทึกรายรับหรือรายจ่ายด้วยตนเอง |
| สถิติ | ดูกราฟสรุปการเงิน หมวดหมู่ที่ใช้จ่ายมากที่สุด และความคืบหน้าการออม |
| เมนู | จัดการโปรไฟล์ รหัสผ่าน ภาษา ธีม และออกจากระบบ |

ทางลัด **จดรายจ่าย**, **สลิป / ใบเสร็จ**, **ธุรกรรม** และ **ออมเงิน** ช่วยให้เข้าสู่ฟังก์ชันที่เกี่ยวข้องได้โดยตรง

## ก.6 การบันทึกรายรับและรายจ่าย

### ก.6.1 เพิ่มรายการใหม่

1. เลือกเมนู **เพิ่มรายการ**
2. เลือกแท็บ **รายรับ** หรือ **รายจ่าย** ตามประเภทของรายการ
3. เลือกหมวดหมู่ เช่น เงินเดือนสำหรับรายรับ หรืออาหารสำหรับรายจ่าย
4. กรอกจำนวนเงินมากกว่า 0 และระบุหมายเหตุหากต้องการ
5. กดปุ่ม **เครื่องหมายบวก (+)** เพื่อเพิ่มข้อมูลลงในรายการรอบันทึก
6. หากต้องการเพิ่มหลายรายการ ให้ทำซ้ำขั้นตอนข้างต้น
7. ตรวจสอบจำนวนรายการและยอดรวม แล้วกด **บันทึก**
8. เมื่อบันทึกสำเร็จ ระบบจะเปิดหน้ารายรับ–รายจ่ายให้ตรวจสอบรายการที่บันทึกแล้ว

การกดเครื่องหมายบวกเป็นเพียงการเพิ่มรายการรอบันทึก ผู้ใช้ต้องกด **บันทึก** เพื่อยืนยันข้อมูลก่อนออกจากหน้า วันที่ของรายการที่เพิ่มด้วยวิธีนี้จะเป็นวันเวลาขณะบันทึก หากต้องการเปลี่ยนวันที่ สามารถแก้ไขภายหลังในรายละเอียดรายการได้

### ก.6.2 แก้ไขหรือลบรายการรอบันทึก

1. แตะรายการรอบันทึกที่ต้องการแก้ไข
2. ปรับจำนวนเงิน หมวดหมู่ หรือหมายเหตุ แล้วกดปุ่ม **เครื่องหมายถูก (✓)** เพื่อยืนยันการแก้ไข
3. หากไม่ต้องการรายการนั้น ให้กดปุ่มลบของรายการ
4. ตรวจสอบรายการที่เหลือก่อนกด **บันทึก**

### ก.6.3 เพิ่มหมวดหมู่ของตนเอง

1. ในส่วนเลือกหมวดหมู่ เลือก **อื่นๆ**
2. กรอกชื่อหมวดหมู่และเลือกไอคอน
3. กด **เพิ่ม** แล้วเลือกหมวดหมู่ดังกล่าวเพื่อใช้กับรายการ

## ก.7 การบันทึกรายจ่ายจากสลิปหรือใบเสร็จ

1. เลือกทางลัด **สลิป / ใบเสร็จ**
2. เลือกภาพจากคลังรูป หรือถ่ายภาพใหม่ โดยใช้ไฟล์ JPG หรือ PNG ขนาดไม่เกิน 5 MB
3. รอให้ระบบอ่านข้อมูลจากภาพ
4. ตรวจสอบยอดเงิน ร้านค้า/ผู้รับ/หมายเหตุ และวันที่ทำรายการให้ตรงกับภาพ พร้อมแก้ไขข้อมูลที่อ่านคลาดเคลื่อน
5. เลือก **หมวดรายจ่าย** ให้เหมาะสม
6. กด **ยืนยันและบันทึกรายจ่าย**
7. เมื่อสำเร็จ ระบบจะแสดงหน้าประวัติ ให้ตรวจสอบรายการที่เพิ่ม

ควรใช้ภาพที่เห็นยอดเงินและวันที่ชัดเจน วางภาพให้ตรงและหลีกเลี่ยงแสงสะท้อน หากอ่านข้อมูลไม่ได้ ให้ลองเลือกภาพใหม่ หรือบันทึกด้วยตนเองผ่านเมนูเพิ่มรายการ

ระบบอ่านภาพบนอุปกรณ์ และเก็บรูปแนบเฉพาะเครื่องที่ใช้งาน รูปแนบไม่ซิงก์ข้ามเครื่อง การอ่านสลิปช่วยกรอกข้อมูลรายจ่ายเท่านั้น ไม่ได้ตรวจสอบหรือยืนยันว่ามีการโอนเงินจริง ผู้ใช้จึงควรตรวจสอบข้อมูลก่อนบันทึกทุกครั้ง

## ก.8 การดูประวัติและจัดการธุรกรรม

### ก.8.1 ดูรายการย้อนหลัง

1. เปิด **กระเป๋าเงิน** แล้วเลือก **ประวัติ** หรือเลือกทางลัด **ธุรกรรม** เพื่อดูหน้ารายรับ–รายจ่าย
2. ในหน้าประวัติ เลือก **ทั้งหมด** เพื่อดูรายการทั้งหมด หรือ **รายวัน** เพื่อดูรายการของวันนี้
3. แตะรายการที่ต้องการดูรายละเอียด เช่น ประเภท หมวดหมู่ จำนวนเงิน วันที่ และหมายเหตุ

### ก.8.2 แก้ไขรายการที่บันทึกแล้ว

1. เปิดรายละเอียดรายการแล้วกด **แก้ไข**
2. ปรับข้อมูลที่ต้องการ เช่น จำนวนเงิน ประเภท หมวดหมู่ วันที่ หรือบันทึกช่วยจำ
3. กด **บันทึก** และตรวจสอบข้อมูลที่เปลี่ยนแปลง

### ก.8.3 ทำซ้ำรายการ

1. เปิดรายละเอียดรายการแล้วกด **ทำซ้ำ**
2. ตรวจสอบและปรับข้อมูลของรายการใหม่ โดยวันที่เริ่มต้นจะเป็นวันเวลาปัจจุบัน
3. กด **บันทึกรายการใหม่** ระบบจะเพิ่มธุรกรรมอีกหนึ่งรายการ จึงควรตรวจสอบไม่ให้ซ้ำกับรายการที่บันทึกไว้แล้ว

### ก.8.4 ลบรายการ

1. เปิดรายละเอียดรายการแล้วกด **ลบ**
2. ตรวจสอบรายการในหน้าต่างยืนยัน
3. กด **ลบ** เพื่อยืนยัน หรือ **ยกเลิก** เพื่อคงรายการไว้
4. ตรวจสอบยอดรวมหลังลบ เนื่องจากการลบธุรกรรมมีผลต่อยอดที่ระบบคำนวณ

## ก.9 การดูยอดเงินและสถิติ

1. เลือก **กระเป๋าเงิน** เพื่อดูยอดคงเหลือรวม รายรับ และรายจ่ายจากข้อมูลที่บันทึก
2. เลือก **สถิติ** เพื่อดูกราฟรายรับ–รายจ่าย หมวดหมู่ที่ใช้จ่ายมากที่สุด และความคืบหน้าของเป้าหมายการออม
3. ใช้ตัวเลือก **วัน**, **เดือน** หรือ **ปี** เพื่อดูข้อมูลตามช่วงเวลาที่สนใจ
4. ตรวจสอบช่วงเวลาที่เลือกก่อนเปรียบเทียบยอดเงินระหว่างหน้าจอ

หากยังไม่มีข้อมูล ระบบจะแสดงข้อความแจ้งว่าไม่มีรายการหรือไม่มีข้อมูลในส่วนนั้น ผู้ใช้สามารถเริ่มบันทึกธุรกรรมเพื่อให้ระบบนำข้อมูลมาแสดงผลได้

## ก.10 การจัดการเป้าหมายการออม

### ก.10.1 สร้างเป้าหมาย

1. เลือกทางลัด **ออมเงิน** หรือเปิด **เป้าหมายการออม** จากหน้ากระเป๋าเงิน
2. กดปุ่มเพิ่มเป้าหมาย
3. กรอกชื่อเป้าหมาย เช่น ซื้อคอมพิวเตอร์ และจำนวนเงินที่ต้องการออม
4. เลือกหมวดหมู่ ระบุวันที่ต้องการให้ถึงเป้าหมาย และเพิ่มหมายเหตุหากต้องการ
5. กด **บันทึก** แล้วตรวจสอบเป้าหมายในรายการ

### ก.10.2 เติมเงินเข้าเป้าหมาย

1. เลือกเป้าหมายที่ต้องการเติมเงิน
2. ในหน้าต่าง **เติมเงินเข้าเป้าหมาย** กรอกจำนวนเงินมากกว่า 0
3. ตรวจสอบว่าจำนวนเงินไม่เกินยอดคงเหลือใน BudgetMate และไม่เกินจำนวนที่ยังขาดจากเป้าหมาย
4. กด **โอนเงิน**
5. ตรวจสอบยอดเงินออมและความคืบหน้าของเป้าหมาย

เมื่อทำรายการสำเร็จ ระบบจะเพิ่มเงินออมในเป้าหมายและสร้างรายการรายจ่ายการออม ทำให้ยอดคงเหลือในกระเป๋าเงินลดลง ตัวอย่างเช่น มียอดคงเหลือ 1,000 บาท แล้วเติมเงินเข้าเป้าหมาย 200 บาท ยอดคงเหลือจะเป็น 800 บาท และยอดออมของเป้าหมายจะเพิ่มขึ้น 200 บาท

### ก.10.3 แก้ไข ปักหมุด และลบเป้าหมาย

- **แก้ไข:** เลือกคำสั่งแก้ไขของเป้าหมาย ปรับข้อมูล แล้วบันทึก โดยยอดเป้าหมายใหม่ต้องไม่น้อยกว่ายอดที่ออมแล้ว
- **ปักหมุด:** ใช้ปุ่มปักหมุดเพื่อให้เป้าหมายแสดงบนหน้าแรก และกดอีกครั้งเพื่อเลิกปักหมุด
- **ลบ:** เลือกคำสั่งลบและยืนยัน ระบบจะลบเฉพาะเป้าหมาย ประวัติการโอนเดิมยังอยู่ และยอดกระเป๋าเงินไม่เปลี่ยน การลบเป้าหมายจึงไม่ได้คืนเงินออมเข้าสู่ยอดคงเหลือโดยอัตโนมัติ

## ก.11 การตั้งค่าบัญชี

### ก.11.1 แก้ไขชื่อและรูปโปรไฟล์

1. เลือก **เมนู** แล้วกด **จัดการโปรไฟล์**
2. แก้ไขชื่อที่แสดงและกด **บันทึก**
3. หากต้องการเปลี่ยนรูป ให้แตะส่วนรูปโปรไฟล์ แล้วเลือกถ่ายรูปใหม่หรือเลือกจากคลังภาพ หากมีรูปอยู่แล้ว สามารถเลือก **ลบรูปโปรไฟล์** ได้

### ก.11.2 เปลี่ยนรหัสผ่าน

1. เลือก **เมนู → รหัสผ่านและความปลอดภัย**
2. กรอกรหัสผ่านเดิม รหัสผ่านใหม่ และยืนยันรหัสผ่านใหม่
3. ตรวจสอบให้รหัสผ่านใหม่ผ่านเงื่อนไขที่แสดงบนหน้าจอ
4. กด **บันทึกรหัสผ่านใหม่** และรอผลการเปลี่ยนรหัสผ่าน

ขั้นตอนนี้ใช้กับบัญชีที่มีรหัสผ่านสำหรับเข้าสู่ระบบด้วยอีเมล ส่วนการเข้าสู่ระบบด้วย Google ให้ใช้ข้อมูลบัญชี Google ของผู้ใช้

### ก.11.3 ภาษาและการแสดงผล

- เลือก **ภาษา** เพื่อเปลี่ยนระหว่างภาษาไทยและภาษาอังกฤษ
- ใช้สวิตช์ **ธีม** เพื่อเปลี่ยนการแสดงผลระหว่างโหมดสว่างและโหมดมืด
- ใช้สวิตช์ **แจ้งเตือนเมื่อทำรายการสำเร็จ** เพื่อเปิดหรือปิดข้อความแจ้งสำเร็จในแอป
- เลือก **เกี่ยวกับเรา** เพื่ออ่านข้อมูลเกี่ยวกับแอปพลิเคชัน

### ก.11.4 ออกจากระบบ

1. ตรวจสอบว่าบันทึกรายการที่ต้องการเรียบร้อยแล้ว
2. เลือก **เมนู → ออกจากระบบ**
3. ระบบจะกลับสู่หน้าเข้าสู่ระบบ หากต้องการใช้งานต่อ ให้เข้าสู่ระบบอีกครั้ง

## ก.12 ปัญหาที่อาจพบและวิธีแก้ไข

| อาการหรือข้อความ | วิธีดำเนินการ |
| --- | --- |
| อีเมลหรือรหัสผ่านไม่ถูกต้อง | ตรวจสอบอีเมลและตัวพิมพ์ของรหัสผ่าน หากจำไม่ได้ให้ใช้ลืมรหัสผ่าน |
| สมัครสมาชิกไม่ได้ | กรอกข้อมูลให้ครบ ตรวจสอบเงื่อนไขรหัสผ่านและอีเมลที่อาจมีบัญชีอยู่แล้ว |
| กดบันทึกรายการไม่ได้ | กรอกจำนวนเงินมากกว่า 0 เลือกหมวดหมู่ และกดเครื่องหมายบวกให้มีรายการรอบันทึกอย่างน้อย 1 รายการ |
| บันทึกหลายรายการสำเร็จเพียงบางรายการ | ตรวจสอบรายการที่ยังรอบันทึกและข้อความผิดพลาด แล้วลองบันทึกรายการที่เหลือ ระบบนำรายการที่สำเร็จแล้วออกจากรายการรอบันทึก |
| อ่านสลิปหรือใบเสร็จไม่ได้ | ตรวจชนิดและขนาดไฟล์ ใช้ภาพชัดเจน แล้วลองใหม่ หรือบันทึกด้วยตนเอง |
| ไม่พบรูปใบเสร็จเมื่อใช้อีกเครื่อง | รูปแนบเก็บเฉพาะเครื่องเดิมและไม่ซิงก์ข้ามเครื่อง |
| เติมเงินเข้าเป้าหมายไม่ได้ | ตรวจยอดคงเหลือและจำนวนที่เป้าหมายยังขาด แล้วลดจำนวนเงินให้ผ่านเงื่อนไข |
| สถิติหรือประวัติไม่แสดงรายการที่ต้องการ | ตรวจสอบวันที่และช่วงเวลาที่เลือก รวมถึงบัญชีที่เข้าสู่ระบบ |
| บันทึกไม่สำเร็จหรือระบบให้เข้าสู่ระบบก่อน | ตรวจสอบการเชื่อมต่ออินเทอร์เน็ตและสถานะการเข้าสู่ระบบ แล้วลองอีกครั้ง |
